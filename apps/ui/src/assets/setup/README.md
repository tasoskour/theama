Optional screenshots for the setup page. Each one is shown directly under the numbered step it belongs to.

Name files `<item>-<n>.png` (also .jpg/.webp) where `item` is `tmdb`, `prowlarr` or `qbittorrent` and `n` is the step number,
for example `prowlarr-3.png`. The Subtitles card covers two sites, so use `subtitles-opensubtitles-<n>.png` and
`subtitles-subdl-<n>.png`. Missing files are simply not shown.

Never include real API keys or passwords in a screenshot.

`icons/` holds the small site badges. Replace them with the official logos (same file names) if you have the right to use them.
